IMPORTANT: Because the header, footer, and sections are loaded with JavaScript fetch(), do not simply double-click index.html. Run it with a local web server:
1. Open the folder in Visual Studio Code.
2. Install the "Live Server" extension if you do not have it.
3. Right-click index.html and choose "Open with Live Server".

CUSTOMIZE
- Replace [Your Name] in index.html and footer.html.
- Replace your.email@example.com with your real email in sections/contact.html and js/main.js.
- Update the education year, skills, projects, and GitHub link.
- Keep all files and folders in the same structure.
- The profile picture is assets/profile.jpg.
